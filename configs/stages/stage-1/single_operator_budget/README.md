# single_operator_budget configs (Stage 1)

| file | what it is | identity |
| --- | --- | --- |
| `design.json` | SOB1, as fixed by the maintainer on 2026-11-19: the question and budget point (N ≈ 2), A's method as the baseline, the three arms' geometries and the operators, profiles, reused selections and gates that build them, the calibration counts, the recovery (A-MIX's units, the order, the memory probe, the durability rules), one evaluation protocol at 8,192 tokens for every model, the registered analysis (three pairs, Holm with m = 3, formal only when complete, no elimination), phases, storage, the cost model's constants | `status: prepared`; a grant binds its sha256 as study identity |
| `selection.json` | generated by `selection.py --write` from the packed search's journal and TPI1's selection (`--check` reproduces it byte for byte): the eight committed DEPTH rounds verbatim with their resume checks, the 16 / 8 heads, the FFN and width gates | study identity |
| `artifacts.json` | the collector's spec for `stage1_single_operator` sessions (every entry may match nothing) | |

Instance facts (geometries, seeds, prices, prefixes, transfer floors) live here and in
`scripts/stages/stage-1/single_operator_budget/`, never in `src/aadistill`. The derived structures, the budget and
each arm's training plan are generated into `logs/stages/stage-1/single_operator_budget/plans/` (`structures.py`,
`proposal.py`, `plan.py`, each with `--check`). Nothing here authorizes anything.
