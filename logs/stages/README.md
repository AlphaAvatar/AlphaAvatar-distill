# logs/stages

Pipeline stages. A stage exists here when an experiment DECLARES it in `configs/experiments/<id>/authorization.json`; stages are never pre-created and never inferred from a name.

| directory | material |
| --- | --- |
| [`stage-1/`](stage-1/) | continuation_b, measurement, phase_a, phase_b, phase_c1, recovery_continuation |
| [`stage-3/`](stage-3/) | e1, e3, e4, e5, e6, e6b, e7, e8, e8b |

Canonical run list: [`../index.json`](../index.json).
